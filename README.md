# SuperStore Sales Analysis — Power BI Project

This project is a Power BI dashboard built using the SuperStore Sales Dataset. The aim is to visualize and explore sales and profit data across various business dimensions to uncover actionable insights.

---

## 📊 Dashboards Included

- **Monthly Profit Analysis**  
  Tracks the profit trend month over month.
  
- **Total Sales Overview**  
  Visualizes total sales across all categories.

- **Sales by Payment Mode**  
  Breakdown of sales based on different payment methods.

- **Sales by Ship Mode**  
  Analysis of sales performance based on shipping modes.

- **Sales by Subcategory**  
  Drills into sales distribution across product subcategories.

- **Sales by Category**  
  High-level sales summary segmented by product categories.

- **Sales by Segment**  
  Evaluates sales performance by customer segments.

- **Sales by Region**  
  Highlights regional sales contributions.
